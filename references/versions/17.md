# Odoo 17

## Verified guidance

- **ORM Architecture**: Single-file ORM located in `odoo/models.py`. Fields, API decorators, and environments are located in `odoo/fields.py` and `odoo/api.py`.
- **List Views (`<tree>`)**: List views in Odoo 17 **must** use the `<tree>` root tag (`<tree string="...">...<field name="..."/></tree>`). The `<list>` tag does **not** exist in Odoo 17.
- **Action `view_mode`**: In `ir.actions.act_window`, the list view mode is specified as `tree,form,kanban` (not `list,form,kanban`).
- **Chatter Structure**: Form views must declare chatter via `<div class="oe_chatter">` containing explicit `<field>` declarations. The self-closing `<chatter/>` tag was introduced in Odoo 18 and is invalid in Odoo 17.
  ```xml
  <div class="oe_chatter">
      <field name="message_follower_ids"/>
      <field name="activity_ids"/>
      <field name="message_ids"/>
  </div>
  ```
- **Product Typing (`detailed_type`)**:
  - In Odoo 17, storable products are defined by `detailed_type = 'product'` (provided by `addons/stock`), while consumables are `detailed_type = 'consu'`.
  - The `is_storable` boolean field does **not** exist in Odoo 17 (it was introduced in Odoo 18 to replace `detailed_type`).
  - Search domains must use `('detailed_type', '=', 'product')` or `('type', '=', 'product')`.
- **Model Name Searching (`_name_search`)**:
  - Custom search-by-name logic must override `_name_search(self, name, domain=None, operator='ilike', limit=100, order=None)`.
  - The modern `_search_display_name()` method does not exist in Odoo 17.
  - `name_get()` is deprecated (since 16.4); override `_compute_display_name()` to customize record display names.
- **Security & Access Checks**:
  - Odoo 17 uses separate methods: `check_access_rights('read'|'write'|'create'|'unlink')` for ACLs and `check_access_rule('read'|'write'|'create'|'unlink')` for record rules.
  - The unified methods `check_access()`, `has_access()`, and `_filtered_access()` do not exist in Odoo 17.
- **Method RPC Protection**:
  - `@api.private` and `@api.readonly` do not exist in Odoo 17.
  - Protect internal methods from RPC exposure by prefixing method names with a leading underscore (e.g., `def _my_internal_method(self):`).
- **SQL Constraints**:
  - Defined using the model attribute `_sql_constraints = [('code_uniq', 'unique(code)', 'Code must be unique!')]`.
  - `models.Constraint` was introduced in Odoo 18/19 and is not available in Odoo 17.
- **Web Controllers & APIs**:
  - Controller routes support `type='http'` and `type='json'` (JSON-RPC 2.0).
  - `type='jsonrpc'` and `type='json2'` do not exist in Odoo 17.
  - Supported `auth` values: `'user'`, `'public'`, and `'none'`.
- **Domains & Expression Combining**:
  - Domains use list-of-tuples prefix notation: `['|', ('state', '=', 'draft'), ('state', '=', 'sent')]`.
  - Programmatic combination uses `from odoo.osv import expression`: `expression.AND([dom1, dom2])` and `expression.OR([dom1, dom2])`.
- **Frontend & Web Assets**:
  - Runs on OWL 2.0. Every JavaScript module requires the header comment `/** @odoo-module **/`.
  - Assets are declared in `__manifest__.py` under `'assets': {'web.assets_backend': [...], 'web.assets_frontend': [...]}`.

## Breaking changes introduced in Odoo 17.x

### 17.0

- **Direct Python Expression Modifiers**: Replaced legacy `attrs="{'invisible': [('state', '=', 'draft')]}"` with direct Python expressions:
  ```xml
  <field name="reference" invisible="state == 'draft'" readonly="state != 'draft'" required="state == 'confirmed'"/>
  <!-- Column-level visibility in tree views -->
  <field name="cost_price" column_invisible="not parent.show_costs"/>
  ```
- **`odoo.tools.SQL` Wrapper**: Introduced safe SQL composition preventing SQL injection. Use `SQL("SELECT %s", value)` instead of manual string formatting. [#134677](https://github.com/odoo/odoo/pull/134677)
- **`name_get()` Deprecation**: Deprecated since 16.4. Use the `display_name` field directly; override `_compute_display_name()` to customize formatting. [#122085](https://github.com/odoo/odoo/pull/122085)
- **OWL 2 Framework**: Frontend migrated entirely to OWL 2 with native ES module syntax (`/** @odoo-module **/`).

### 17.1

- `_flush_search()` deprecated. Flushing is handled internally using metadata in `SQL` objects.
  [#144747](https://github.com/odoo/odoo/pull/144747)

### 17.2

- `group_operator` field attribute renamed to `aggregator`.
  [#127353](https://github.com/odoo/odoo/pull/127353)

  ```python
  # Before
  total = fields.Float(group_operator='sum')
  # After
  total = fields.Float(aggregator='sum')
  ```
- Grouping/aggregating/ordering by related non-stored fields is supported.

### 17.3

- Group by date part numbers in `read_group` / `_read_group` and search domains.
  [#159528](https://github.com/odoo/odoo/pull/159528)

### 17.4

- Internal domain operator `inselect` removed. Use `in` with a `Query` or `SQL` object instead.
  [#171371](https://github.com/odoo/odoo/pull/171371)

  ```python
  # Before
  domain = [('id', 'inselect', (subquery, params))]
  # After
  domain = [('id', 'in', query_or_sql_object)]
  ```

## Upgrade & Migration Focus for Odoo 17

When developing for or upgrading modules to Odoo 17:
- **Views**: Replace all `<list>` tags with `<tree>`. Ensure `<field ... attrs="..."/>` is converted to `invisible="..."`, `readonly="..."`, and `required="..."`.
- **Chatter**: Use `<div class="oe_chatter">` with `<field name="message_follower_ids"/>`, `<field name="activity_ids"/>`, and `<field name="message_ids"/>`.
- **Products**: Query `('detailed_type', '=', 'product')` instead of `('is_storable', '=', True)`.
- **Searching**: Override `_name_search()` for custom lookup; override `_compute_display_name()` instead of `name_get()`.
- **Security Checks**: Call `check_access_rights()` and `check_access_rule()` instead of `check_access()`.
- **Controllers**: Use `type='json'` (JSON-RPC) or `type='http'`. Do not use `type='jsonrpc'`.
- **SQL Queries**: Wrap queries in `odoo.tools.SQL` and explicitly call `self.env.flush_all()` before raw SQL reads.
